# 🎯 پاوربینت هوشمند - نسخه ساده

## ✨ ویژگی‌های جدید

این نسخه **بدون نیاز به API Key** کار می‌کند و کاملاً رایگان است!

### چرا این نسخه بهتر است؟

✅ **بدون API Key** - نیازی به تنظیمات پیچیده نیست
✅ **سرعت بالا** - همه چیز در مرورگر شما اجرا می‌شود
✅ **رایگان 100%** - بدون محدودیت استفاده
✅ **حریم خصوصی** - هیچ داده‌ای به سرور ارسال نمی‌شود
✅ **آسان** - فقط متن بنویس و دانلود کن

## 🚀 نحوه استفاده

### قدم 1: نصب و اجرا

```bash
# نصب dependencies
npm install

# اجرای پروژه
npm run dev
```

### قدم 2: استفاده از برنامه

1. به http://localhost:3000 برو
2. متن خود را وارد کن (یا روی "بارگذاری متن نمونه" کلیک کن)
3. روی "🚀 ساخت پرزنتیشن" کلیک کن
4. پیش‌نمایش اسلایدها را ببین
5. روی "📥 دانلود PowerPoint" کلیک کن

همین! فایل .pptx آماده است.

## 📝 فرمت متن

```
عنوان پرزنتیشن

عنوان اسلاید اول
نکته اول
نکته دوم
نکته سوم

عنوان اسلاید دوم
نکته اول
نکته دوم
```

### نکات مهم:

- **خط اول** = عنوان کل پرزنتیشن
- **خط خالی** = جداکننده بین اسلایدها
- **هر گروه خطوط** = یک اسلاید جدید
- **5 خط** = حداکثر محتوای هر اسلاید

## 🎨 ویژگی‌های طراحی

- اسلاید عنوان با پس‌زمینه آبی-بنفش
- اسلایدهای محتوا با header بار و bullet points
- اسلاید جمع‌بندی با پس‌زمینه بنفش-صورتی
- پشتیبانی کامل از RTL و زبان فارسی
- فونت Arial برای سازگاری با PowerPoint

## 🔧 ساختار فایل‌ها

```
src/
├── app/
│   └── page.tsx              # صفحه اصلی (ساده شده)
├── components/
│   ├── SlideGenerator.tsx    # ورودی متن
│   └── SimpleSlidePreview.tsx # نمایش پیش‌نمایش
└── lib/
    ├── slideGenerator.ts      # تولید اسلایدها از متن
    └── pptxExport.ts         # اکسپورت به PowerPoint
```

- **پرزنتیشن‌های ساده**: متن خود را به اسلاید تبدیل کنید
